# Warroom warm redesign — draft 01

## Direction

On 2026-11-16, the user rejected the existing UI as a whole and requested a redesign using emil-design-eng. The user selected: “อบอุ่น เป็นกันเอง ลดความรู้สึกว่าเป็นหน้าระบบ”. This approves the direction, not the specific prototype or a production replacement.

The draft uses warm cream, brown text, terracotta accents, a quiet conversation illustration, horizontal navigation, and one dominant status statement. Five AI capabilities and their provider/requested model remain visible. Response model names are available in a disclosure. The latest receive, send, and delivery evidence stay distinct. A stale snapshot never becomes a current success state.

## Try the prototype

Run `node docs/prototypes/serve-warroom.mjs`, then open http://127.0.0.1:4174.
The server allows only the prototype HTML/JS and three public font files. It cannot serve chats, credentials, or other repository files. No API calls, bot operations, real accounts, or production changes are involved.

Controls: connected/disconnected/stale/no-data scenarios, overview/history tabs, response-model disclosure, and a help dialog. All names, times, events, and model IDs are synthetic and explicitly labeled. History is a fixed sample rather than generated by scenario changes.

## Interaction decisions

- Frequently used tabs and scenario changes update instantly.
- Pointer presses use a subtle 0.97 scale; keyboard input disables it.
- The occasional guidance dialog uses an interrupt-free native dialog, 180 ms ease-out entrance, instant exit, focus containment, and Escape dismissal.
- Reduced motion removes transforms and the dialog entrance animation.
- Hover feedback only applies to fine pointers that support hover.
