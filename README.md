# บอทสรุปงานกลุ่ม WhatsApp

บอทจะเข้าไปอยู่ในกลุ่ม WhatsApp แล้วทำงานแบบนี้:

- เก็บข้อความในกลุ่มไว้ในเครื่อง (`data/messages.db`)
- พอมีคนส่งรูปหรือ PDF ให้ AI ดูและเขียนคำอธิบายสั้นๆ เก็บไว้ เช่น "Render 3D บ้าน 2 ชั้นสไตล์โมเดิร์น หลังคาจั่ว ผนังขาว"
- สรุปงานเมื่อมีคนพิมพ์คำสั่งในกลุ่ม และสรุปอัตโนมัติทุกวันตามเวลาที่ตั้ง (ค่าเริ่มต้น 18:00)

สรุปจะแยกเป็นหัวข้อ: ✅ ตกลงแล้ว · 📌 ใครต้องทำอะไร · ⏳ ยังค้าง · 🖼️ ไฟล์/รูปสำคัญ · 🔗 ลิงก์
และจะเช็กว่างานค้างจากสรุปครั้งก่อนเสร็จหรือยัง

> ⚠️ **ข้อควรรู้:** บอทล็อกอินแบบ "อุปกรณ์ที่ลิงก์" เหมือน WhatsApp Web โดยใช้ไลบรารี Baileys ซึ่งไม่ใช่ API ทางการ
> WhatsApp อาจแบนเบอร์ที่ใช้วิธีนี้ **ควรใช้เบอร์แยกสำหรับบอท** แล้วเชิญเบอร์นั้นเข้ากลุ่ม และบอกสมาชิกว่ามีบอทอ่านข้อความอยู่

## ติดตั้ง

ต้องมี Node.js 22.5 ขึ้นไป

```bash
npm install
cp .env.example .env
```

เปิดไฟล์ `.env` แล้วเลือก AI ด้วย `AI_PROVIDER=openai` หรือ `AI_PROVIDER=claude`
ใส่ key ที่ตรงกัน (`OPENAI_API_KEY` หรือ `ANTHROPIC_API_KEY`) และใส่ชื่อกลุ่มใน `WATCH_GROUPS`

## ลองกับไฟล์ export ก่อน (ไม่ต้องต่อ WhatsApp)

```bash
npm run summarize-export -- "~/Downloads/WhatsApp Chat - EXAMPLE STUDIO (1).zip"
```

- `--no-media` ไม่ส่งรูปให้ AI ดู (เร็วและถูกกว่า)
- `--transcript` แสดงเฉพาะข้อความที่อ่านได้ ไม่เรียก AI
- `--since 2026-11-08` สรุปตั้งแต่วันที่กำหนด

ผลสรุปจะถูกบันทึกไว้ในโฟลเดอร์ `output/`

## เปิดบอท

```bash
npm start
```

1. ครั้งแรกจะมี QR ขึ้นในเทอร์มินัล
2. บนมือถือที่ใช้เบอร์ของบอท: WhatsApp → การตั้งค่า → อุปกรณ์ที่ลิงก์ → ลิงก์อุปกรณ์ → สแกน QR
   (ถ้าสแกนไม่สะดวก ให้ใส่ `PAIRING_NUMBER` ใน `.env` แล้วใช้รหัสจับคู่แทน)
3. เชิญเบอร์บอทเข้ากลุ่ม
4. บอทจะเก็บข้อความตั้งแต่ตอนนั้นเป็นต้นไป ต้องเปิดเครื่องทิ้งไว้ บอทจึงจะได้รับข้อความ

ข้อมูลล็อกอินเก็บไว้ที่ `data/auth` ถ้าอยากล็อกอินใหม่ให้ลบโฟลเดอร์นี้

## งานและการเตือน

- **จดงานเอง:** หลังแชทเงียบไป 3 นาที บอทจะอ่านข้อความใหม่ แล้วจดงานที่มีคนสั่งหรือรับปากไว้ พร้อมปิดงานที่มีคนบอกว่าส่งแล้ว
- **คุยกับบอท:** แท็ก @บอท หรือขึ้นต้นข้อความด้วย "บอท" เช่น
  - `บอท พรุ่งนี้บ่าย 2 เตือน @Somchai ส่ง Render`
  - `บอท ทุกวันจันทร์ 9 โมง เตือนทุกคนอัปเดตงาน`
  - `บอท งาน #3 เสร็จแล้ว` / `บอท เลื่อนงาน #3 เป็นศุกร์นี้`
  - `บอท ลิงก์ Drive ล่าสุดอยู่ไหน`
- **ข้อความเตือน:** ตอบกลับว่า "เสร็จแล้ว" หรือกด ✅ เพื่อปิดงาน ตอบ "เลื่อน 1 ชม." เพื่อเลื่อน ถ้ายังไม่ปิด บอทจะทวงซ้ำอีก 2 ครั้ง ห่างกันครั้งละ 3 ชม. และไม่ทวงช่วง 21:00–08:00
- **สรุปเช้า 08:00:** บอกงานที่เลยกำหนด งานที่ครบกำหนดวันนี้ การเตือนของวันนี้ และงานค้างอื่นๆ

- **ตอบคำถามเกี่ยวกับตัวเอง:** ถ้ามีคนถามเรื่องบอทในกลุ่ม เช่น "ai นี้เก็บข้อมูลไว้ไหน" บอทจะตอบเองแม้ไม่ได้แท็ก (ปิดได้ด้วย `ANSWER_BOT_QUESTIONS=false`) ข้อมูลที่บอทใช้ตอบอยู่ใน `src/about.js` ถ้าเปลี่ยนความสามารถของบอท ต้องแก้ไฟล์นี้ด้วย

## แฟ้มข้อมูลลูกค้า (สูงสุด 10 รายต่อกลุ่ม)

เหมาะกับทีมสถาปัตย์และรับเหมาก่อสร้างที่คุยเรื่องลูกค้าหลายเจ้าปนกันในกลุ่มเดียว:
- **ขึ้นทะเบียนลูกค้าใหม่ (ต้องสั่งตรง):** พิมพ์ `บอท เพิ่มลูกค้า คุณสมชาย (บ้านลาดพร้าว) งบ 8 ล้าน ทำเลลาดพร้าว 71 เฟสออกแบบ` หรือ `/ลูกค้า เพิ่ม ...` (เก็บลูกค้าที่เปิดอยู่ได้สูงสุด 10 รายต่อกลุ่ม ปรับได้ด้วย `MAX_CLIENTS`)
- **ช่วงงานตั้งแต่ต้นน้ำยันปลายน้ำ:** `บรีฟ/สำรวจ` → `ออกแบบ 3D/แปลน` → `BOQ/สัญญา/ขออนุญาต` → `ก่อสร้าง` → `เก็บ Defect/ส่งมอบ`
- **บันทึกแยก 5 หมวด:** `บรีฟ/โจทย์`, `สเปกวัสดุ`, `สั่งแก้/VO`, `หน้างาน/Defect`, และ `ลิงก์`
  - สั่งตรงได้ เช่น `บอท จำไว้ว่า บ้านลาดพร้าว เปลี่ยนกระเบื้องห้องน้ำชั้น 2 เป็นสีเทาด้าน`
  - หรือให้บอทสกัดจากแชทให้อัตโนมัติหลังแชทเงียบ 3 นาที **เฉพาะเมื่อข้อความเอ่ยชื่อหรือคำเรียกของลูกค้าที่ลงทะเบียนไว้แล้ว** พร้อมแจ้งเลขโน้ต (`#N1`) เผื่อสั่งลบด้วย `/ลบโน้ต 1`
- **ดูข้อมูล:** พิมพ์ `/ลูกค้า` เพื่อดูภาพรวมทั้ง 10 เจ้า หรือ `/ลูกค้า บ้านลาดพร้าว` เพื่อเปิดแฟ้มครบทุกหมวดพร้อมงานค้างของบ้านนั้น
- **บันทึกที่มีที่มาและประวัติการแก้:**
  - ดูบันทึกฉบับปัจจุบัน: `/โน้ต 3`
  - ดูข้อความแชทต้นทางที่เป็นที่มาของบันทึก: `/ที่มา 3`
  - ดูประวัติการแก้ไขทุกฉบับ: `/ประวัติโน้ต 3`
  - แก้ไขบันทึกโดยเก็บฉบับเดิมไว้ในประวัติ: `/แก้โน้ต 3 ข้อความใหม่` (หรือสั่ง `บอท แก้โน้ต #N3 เป็น...`)

## ภาพเรนเดอร์จากสเก็ต

บอทใช้โมเดล `gpt-image-2.6-sunburst` เปลี่ยนภาพ SketchUp ให้เป็นภาพเหมือนจริง ไม่ต้องผูกกับแฟ้มลูกค้า
- **เรนเดอร์:** ส่งสเก็ตพร้อมพิมพ์ในข้อความเดียวกันว่า `บอท เรนเดอร์ warm neutral` (สไตล์จะพิมพ์หรือไม่ก็ได้)
  - หรือตอบกลับรูปสเก็ตที่ส่งไว้แล้ว ด้วย `บอท เรนเดอร์ ...`
  - หรือพิมพ์ `บอท เรนเดอร์` เฉยๆ บอทจะใช้รูปล่าสุดที่คุณส่งภายใน 30 นาที ถ้าไม่มี บอทจะขอรูป แล้วเริ่มทันทีเมื่อคุณส่งรูปตามมา (ภายใน 10 นาที)
- **สิ่งที่คงไว้ตามสเก็ต:** เฟอร์นิเจอร์ทุกชิ้น ตำแหน่ง ขนาด สัดส่วน มุมกล้อง ผนัง และช่องเปิด
  **สิ่งที่ AI เติมได้:** วัสดุ สี แสง เงา บรรยากาศ วิวนอกหน้าต่าง และของตกแต่งเล็กๆ (ไม่ใส่ตัวหนังสือหรือป้าย)
- **ขนาดภาพ:** ภาพที่ได้มีขนาดและกรอบภาพเท่ากับรูปต้นทางเป๊ะ (บอทเติมขอบให้พอดีกับโมเดลก่อน แล้วตัดกลับเท่าเดิม) ใช้เวลาราว 1 นาที
- **ปรับภาพ:** ตอบกลับภาพเรนเดอร์ว่า เช่น `ไฟอุ่นขึ้น` หรือ `ผนังเป็นสีเทา` บอทจะแก้ต่อจากภาพนั้น
- **ดูยอดใช้งาน:** `/เรนเดอร์` บอกจำนวนภาพวันนี้และ 7 วัน ตั้งเพดานต่อวันได้ด้วย `MAX_RENDERS_PER_DAY` (ค่าเริ่มต้น 0 = ไม่จำกัด)
- ⚠️ บอทไม่วาดจากข้อความล้วน ต้องมีภาพต้นทางเสมอ (รับเฉพาะไฟล์รูป ยังไม่รับ PDF) ทุกข้อความที่ตอบกลับภาพเรนเดอร์ถือเป็นคำสั่งปรับภาพ และ AI อาจยังคลาดเคลื่อนบางจุด ควรตรวจเทียบกับแบบต้นฉบับก่อนส่งลูกค้า

## ถามบอทและลบข้อมูล (เฟส 2)

บอทรู้จักความสามารถเฟส 2 แล้ว ทั้งข้อความ `/แนะนำ` และข้อมูลที่ใช้ตอบคำถามอย่าง “บอททำอะไรได้บ้าง” หรือ “บอทลบข้อมูลได้ไหม” อยู่ใน `src/about.js` ถ้าเพิ่งอัปเดตโค้ด ต้องรีสตาร์ตบอทก่อนให้ตัวที่รันอยู่โหลดข้อมูลใหม่นี้

แท็ก @บอท หรือขึ้นต้นด้วย “บอท” เช่น “บอท ลิงก์ Drive ล่าสุดอยู่ไหน” หรือ “บอท ลูกค้าขอแก้อะไรบ้าง” บอทใช้แชทล่าสุดร่วมกับการค้นคำสำคัญในประวัติที่เก็บของกลุ่มนี้ โดยดึงผลค้นล่าสุดได้สูงสุด 40 ข้อความ รวมถึงคำอธิบายรูป/PDF แล้วให้ AI ตอบพร้อมชื่อผู้ส่งและวันที่/เวลาอ้างอิง ถ้าไม่พบ ให้ถามเจาะจงด้วยชื่อไฟล์หรือคำสำคัญ

คำว่า “ล่าสุด” หมายถึงล่าสุดจากข้อความที่ค้นพบ บอทยังเปิด Drive เพื่อเช็กไฟล์จริงไม่ได้ การค้นแบบคำสำคัญอาจตกหล่น โดยเฉพาะคำที่สะกดต่างกัน และ AI อาจตอบผิดได้

**ลบข้อมูล:** แอดมินกลุ่มพิมพ์ `/ลบข้อมูล` หรือ “บอท ลบข้อมูลทั้งหมด” บอทจะแจ้งขอบเขตและให้รหัส จากนั้นแอดมินคนเดิมพิมพ์ `/ลบข้อมูล ยืนยัน <รหัส>` ภายใน 5 นาที หรือ `/ลบข้อมูล ยกเลิก` เพื่อยกเลิก ไม่ต้องเรียก AI ในขั้นตอนนี้

ลบแชท สรุป งาน การเตือน และไฟล์รูป/PDF ในโฟลเดอร์สื่อของกลุ่มนี้ที่บอทเก็บไว้บนเครื่อง ย้อนคืนไม่ได้ ไม่ลบข้อความบน WhatsApp ไฟล์ใน Drive ข้อมูลกลุ่มอื่น รายชื่อผู้ติดต่อ หรือกุญแจล็อกอิน และไม่รวมไฟล์ export/สำเนา/ล็อกที่อยู่นอกฐานข้อมูลนี้ เก็บเพียงรหัสกลุ่มและเวลาที่ลบเพื่อกันประวัติเก่าถูกนำกลับมา บอทยังเก็บข้อความใหม่หลังวินาทีที่ลบตามปกติ การลบนี้ไม่ใช่การล้างร่องรอยจากดิสก์หรือสำเนาที่ส่งให้ผู้ให้บริการ AI แล้ว

## ข้อจำกัดของบอทที่รู้อยู่

บอทบอกข้อจำกัดเหล่านี้เองเมื่อมีคนถามในกลุ่ม (ข้อความอยู่ใน `src/about.js`):
1. ต้องมีคอมพิวเตอร์เปิดและต่อเน็ตตลอด เครื่องหลับหรือพับจอ MacBook บอทหยุด ยังไม่ได้ย้ายไปรันบนเซิร์ฟเวอร์
2. พอกลับมาออนไลน์: ตอบคำสั่งที่ค้างได้ถ้าไม่เกิน 12 ชม. ส่งการเตือนที่พลาดพร้อมบอกว่าช้า ส่งสรุปเช้าที่พลาดถ้ายังไม่เกินเที่ยง และสรุปเย็นถ้ายังไม่เกิน 23:00 เลยจากนั้นข้ามไป
3. ออฟไลน์นานเกินประมาณ 2 สัปดาห์ WhatsApp อาจปลดการลิงก์ ต้องสแกน QR ใหม่
4. ตอนตอบคำถาม อ่านแชทล่าสุด 60 ข้อความใน 7 วัน และค้นคำสำคัญในแชทที่เก็บของกลุ่มนี้เพิ่มสูงสุด 40 ข้อความ การค้นอาจไม่ครบ ถ้าไม่พบลองระบุชื่อไฟล์/คำสำคัญให้ชัดขึ้น
5. ข้อมูลอยู่บนเครื่องเดียว ยังไม่มีสำรองข้อมูลอัตโนมัติ
6. เก็บแฟ้มลูกค้าที่เปิดอยู่ได้สูงสุด 10 รายต่อกลุ่ม (`MAX_CLIENTS`) ต้องสั่งเพิ่มลูกค้าใหม่ตรงๆ และบอทจะสกัดข้อมูลเข้าแฟ้มอัตโนมัติเฉพาะเมื่อเอ่ยชื่อหรือคำเรียกของลูกค้าที่มีในทะเบียนแล้วเท่านั้น
7. เปิดบอทได้ทีละตัว
8. แอดมินกลุ่มสั่งลบข้อมูลที่บอทเก็บของกลุ่มนี้ได้ด้วย `/ลบข้อมูล` และยืนยันรหัสภายใน 5 นาที (ลบทั้งแชท สรุป งาน การเตือน แฟ้มลูกค้า และไฟล์รูป/PDF ของกลุ่มนี้)
9. ฟังเสียง ดูวิดีโอ เปิดลิงก์ Google Drive ไม่ได้ ยังไม่เชื่อม Google Calendar
10. AI อาจเข้าใจผิด และการเชื่อม WhatsApp แบบนี้ไม่ใช่ช่องทางทางการ เบอร์อาจถูกจำกัดได้

**เมื่อแก้ข้อใดข้อหนึ่งได้แล้ว (เช่น เพิ่มสำรองข้อมูล หรือระบบค้นทั้งประวัติ) ต้องแก้ `src/about.js` และรายการนี้ให้ตรงกันด้วย** ไม่เช่นนั้นบอทจะตอบผิดเรื่องตัวเอง

## ถ้าปิดเครื่องหรือบอทดับ

พอเปิดบอทกลับมา บอทจะต่อ WhatsApp เองโดยไม่ต้องสแกน QR (ถ้าออฟไลน์ไม่นานเกินประมาณ 2 สัปดาห์) แล้วทำงานที่ค้างต่อให้:
- ข้อความที่ส่งเข้ากลุ่มระหว่างนั้นถูกเก็บครบ เพราะ WhatsApp ส่งตามมาให้
- คำสั่งหรือคำถามถึงบอทที่ส่งมาภายใน 12 ชม. (`OFFLINE_REPLY_HOURS`) บอทจะตอบ และบอกว่าตอบช้าเพราะออฟไลน์
- การเตือนที่เลยเวลา บอทส่งทันทีพร้อมบอกเวลาเดิม ส่วนการเตือนซ้ำจะเดินต่อจากรอบถัดไป
- สรุปเช้าที่พลาด บอทส่งให้ถ้ายังไม่เกินเที่ยง สรุปเย็นที่พลาด บอทส่งให้ถ้ายังไม่เกิน 23:00
- รูปที่ยังอธิบายไม่เสร็จ บอททำต่อ และงานในแชทที่ยังไม่ได้จด บอทจดต่อ

**ให้บอทเปิดเองตลอด (macOS):** `npm run autostart -- install` บอทจะรันเบื้องหลัง เปิดเองทุกครั้งที่ล็อกอิน เปิดใหม่ถ้าดับ และกันเครื่องหลับระหว่างรัน ดูสถานะด้วย `npm run autostart -- status` ถอดออกด้วย `npm run autostart -- uninstall`
ข้อจำกัด: MacBook ที่พับจอยังหลับอยู่ดี ยกเว้นเสียบไฟและต่อจอนอก และบอทเปิดได้ทีละตัวเท่านั้น

## คำสั่งในกลุ่ม

| คำสั่ง | ทำอะไร |
|---|---|
| `/สรุป` | สรุปตั้งแต่สรุปครั้งล่าสุด (ครั้งแรกจะสรุป 24 ชม. ล่าสุด) |
| `/สรุป 3 ชม.` หรือ `/สรุป 2 วัน` | สรุปย้อนหลังตามช่วงเวลาที่ระบุ |
| `/งานค้าง` | ดูเฉพาะงานที่ต้องทำและเรื่องที่ยังค้าง (7 วันล่าสุด) |
| `/งาน` | งานที่ยังเปิดอยู่ทั้งหมด พร้อมเลขงาน |
| `/เสร็จ 3` · `/ยกเลิก 3` | ปิดงานหรือยกเลิกงาน #3 |
| `/ลูกค้า` · `/ลูกค้า ชื่อบ้าน` | ดูรายชื่อลูกค้าทั้งหมด (สูงสุด 10 ราย) หรือเปิดแฟ้มข้อมูล+งานค้างรายบ้าน |
| `/โน้ต 3` | ดูบันทึก `#N3` ในแฟ้มลูกค้า (ฉบับปัจจุบัน) |
| `/ที่มา 3` | ดูข้อความแชทต้นทางที่เป็นที่มาของบันทึก `#N3` |
| `/ประวัติโน้ต 3` | ดูประวัติการแก้ไขทุกฉบับของบันทึก `#N3` |
| `/แก้โน้ต 3 ข้อความใหม่` | แก้ไขบันทึก `#N3` เป็นข้อความใหม่ พร้อมเก็บประวัติ |
| `/ลบโน้ต 3` | ลบบันทึก `#N3` ในแฟ้มลูกค้าที่บอทจำผิด |
| `/เรนเดอร์` | วิธีสั่งเรนเดอร์ และจำนวนภาพที่เรนเดอร์ไปวันนี้ / 7 วัน |
| `/สถิติ` | งานใหม่ งานที่ปิดได้ และเวลาเฉลี่ยในการปิดงาน (7 วันล่าสุด) |
| `/แนะนำ` | บอทแนะนำตัว: ทำอะไรได้ ข้อจำกัด และข้อมูลไปไหน |
| `/ลบข้อมูล` | แอดมินเริ่มลบข้อมูลของกลุ่มนี้ ต้องยืนยันรหัสภายใน 5 นาที |
| `/ช่วย` | แสดงรายการคำสั่ง |

ถ้าไม่อยากให้สรุปอัตโนมัติโพสต์ในกลุ่ม ให้ตั้ง `SUMMARY_TARGET=owner` และใส่ `OWNER_NUMBER` สรุปจะถูกส่งเป็นแชทส่วนตัวแทน

## ค่าใช้จ่าย

ค่าเริ่มต้นใช้ `gpt-6.1-terra` สำหรับ OpenAI และ `claude-opus-5-5` สำหรับ Claude
ค่าใช้จ่ายส่วนใหญ่มาจากการให้ AI ดูรูป ถ้าอยากประหยัด ให้ตั้ง `DESCRIBE_MEDIA=false` หรือเปลี่ยน `OPENAI_MODEL` / `CLAUDE_MODEL` เป็นรุ่นที่ถูกกว่า

## โครงสร้างไฟล์

- `src/bot.js` ต่อ WhatsApp รับข้อความ จัดการคำสั่ง และตั้งเวลาสรุปอัตโนมัติ
- `src/summarize.js` สร้างบทสนทนาให้ AI อ่าน และกำหนดรูปแบบสรุป
- `src/describe.js` ให้ AI อธิบายรูปและ PDF
- `src/ai.js` เรียก AI ตาม `AI_PROVIDER` (OpenAI หรือ Claude)
- `src/tasks.js` งาน การเตือน และสรุปเช้า
- `src/db.js` ฐานข้อมูล SQLite
- `src/export-parser.js` + `src/export-cli.js` อ่านไฟล์ export ของ WhatsApp แล้วสรุป
