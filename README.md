# บอทสรุปงานกลุ่ม WhatsApp

บอทจะเข้าไปอยู่ในกลุ่ม WhatsApp แล้วทำงานแบบนี้:

- เก็บข้อความในกลุ่มไว้ในเครื่อง (`data/messages.db`)
- พอมีคนส่งรูปหรือ PDF ให้ AI ดูและเขียนคำอธิบายสั้นๆ เก็บไว้ เช่น "Render 3D บ้าน 2 ชั้นสไตล์โมเดิร์น หลังคาจั่ว ผนังขาว"
- สรุปงานเมื่อมีคนพิมพ์คำสั่งในกลุ่ม และสรุปอัตโนมัติทุกวันตามเวลาที่ตั้ง (ค่าเริ่มต้น 18:00)

สรุปจะแยกเป็นหัวข้อ: ✅ ตกลงแล้ว · 📌 ใครต้องทำอะไร · ⏳ ยังค้าง · 🖼️ ไฟล์/รูปสำคัญ · 🔗 ลิงก์
และจะเช็กว่างานค้างจากสรุปครั้งก่อนเสร็จหรือยัง

> ⚠️ **ข้อควรรู้:** บอทล็อกอินแบบ "อุปกรณ์ที่ลิงก์" เหมือน WhatsApp Web โดยใช้ไลบรารี Baileys ซึ่งไม่ใช่ API ทางการ
> WhatsApp อาจแบนเบอร์ที่ใช้วิธีนี้ **ควรใช้เบอร์แยกสำหรับบอท** แล้วเชิญเบอร์นั้นเข้ากลุ่ม และบอกสมาชิกว่ามีบอทอ่านข้อความอยู่

## ติดตั้ง

ต้องมี Node.js 22.5 ขึ้นไป

```bash
npm install
cp .env.example .env
```

เปิดไฟล์ `.env` แล้วเลือก AI ด้วย `AI_PROVIDER=openai` หรือ `AI_PROVIDER=claude`
ใส่ key ที่ตรงกัน (`OPENAI_API_KEY` หรือ `ANTHROPIC_API_KEY`) และใส่ชื่อกลุ่มใน `WATCH_GROUPS`

## ลองกับไฟล์ export ก่อน (ไม่ต้องต่อ WhatsApp)

```bash
npm run summarize-export -- "~/Downloads/WhatsApp Chat - EXAMPLE STUDIO (1).zip"
```

- `--no-media` ไม่ส่งรูปให้ AI ดู (เร็วและถูกกว่า)
- `--transcript` แสดงเฉพาะข้อความที่อ่านได้ ไม่เรียก AI
- `--since 2026-11-08` สรุปตั้งแต่วันที่กำหนด

ผลสรุปจะถูกบันทึกไว้ในโฟลเดอร์ `output/`

## เปิดบอท

```bash
npm start
```

1. ครั้งแรกจะมี QR ขึ้นในเทอร์มินัล
2. บนมือถือที่ใช้เบอร์ของบอท: WhatsApp → การตั้งค่า → อุปกรณ์ที่ลิงก์ → ลิงก์อุปกรณ์ → สแกน QR
   (ถ้าสแกนไม่สะดวก ให้ใส่ `PAIRING_NUMBER` ใน `.env` แล้วใช้รหัสจับคู่แทน)
3. เชิญเบอร์บอทเข้ากลุ่ม
4. บอทจะเก็บข้อความตั้งแต่ตอนนั้นเป็นต้นไป ต้องเปิดเครื่องทิ้งไว้ บอทจึงจะได้รับข้อความ

ข้อมูลล็อกอินเก็บไว้ที่ `data/auth` ถ้าอยากล็อกอินใหม่ให้ลบโฟลเดอร์นี้

## งานและการเตือน

- **จดงานเอง:** หลังแชทเงียบไป 3 นาที บอทจะอ่านข้อความใหม่ แล้วจดงานที่มีคนสั่งหรือรับปากไว้ พร้อมปิดงานที่มีคนบอกว่าส่งแล้ว
- **คุยกับบอท:** แท็ก @บอท หรือขึ้นต้นข้อความด้วย "บอท" เช่น
  - `บอท พรุ่งนี้บ่าย 2 เตือน @Somchai ส่ง Render`
  - `บอท ทุกวันจันทร์ 9 โมง เตือนทุกคนอัปเดตงาน`
  - `บอท งาน #3 เสร็จแล้ว` / `บอท เลื่อนงาน #3 เป็นศุกร์นี้`
  - `บอท ลิงก์ Drive ล่าสุดอยู่ไหน`
- **ข้อความเตือน:** ตอบกลับว่า "เสร็จแล้ว" หรือกด ✅ เพื่อปิดงาน ตอบ "เลื่อน 1 ชม." เพื่อเลื่อน ถ้ายังไม่ปิด บอทจะทวงซ้ำอีก 2 ครั้ง ห่างกันครั้งละ 3 ชม. และไม่ทวงช่วง 21:00–08:00
- **สรุปเช้า 08:00:** บอกงานที่เลยกำหนด งานที่ครบกำหนดวันนี้ การเตือนของวันนี้ และงานค้างอื่นๆ

## คำสั่งในกลุ่ม

| คำสั่ง | ทำอะไร |
|---|---|
| `/สรุป` | สรุปตั้งแต่สรุปครั้งล่าสุด (ครั้งแรกจะสรุป 24 ชม. ล่าสุด) |
| `/สรุป 3 ชม.` หรือ `/สรุป 2 วัน` | สรุปย้อนหลังตามช่วงเวลาที่ระบุ |
| `/งานค้าง` | ดูเฉพาะงานที่ต้องทำและเรื่องที่ยังค้าง (7 วันล่าสุด) |
| `/งาน` | งานที่ยังเปิดอยู่ทั้งหมด พร้อมเลขงาน |
| `/เสร็จ 3` · `/ยกเลิก 3` | ปิดงานหรือยกเลิกงาน #3 |
| `/สถิติ` | งานใหม่ งานที่ปิดได้ และเวลาเฉลี่ยในการปิดงาน (7 วันล่าสุด) |
| `/ช่วย` | แสดงรายการคำสั่ง |

ถ้าไม่อยากให้สรุปอัตโนมัติโพสต์ในกลุ่ม ให้ตั้ง `SUMMARY_TARGET=owner` และใส่ `OWNER_NUMBER` สรุปจะถูกส่งเป็นแชทส่วนตัวแทน

## ค่าใช้จ่าย

ค่าเริ่มต้นใช้ `gpt-6.1-terra` สำหรับ OpenAI และ `claude-opus-5-5` สำหรับ Claude
ค่าใช้จ่ายส่วนใหญ่มาจากการให้ AI ดูรูป ถ้าอยากประหยัด ให้ตั้ง `DESCRIBE_MEDIA=false` หรือเปลี่ยน `OPENAI_MODEL` / `CLAUDE_MODEL` เป็นรุ่นที่ถูกกว่า

## โครงสร้างไฟล์

- `src/bot.js` ต่อ WhatsApp รับข้อความ จัดการคำสั่ง และตั้งเวลาสรุปอัตโนมัติ
- `src/summarize.js` สร้างบทสนทนาให้ AI อ่าน และกำหนดรูปแบบสรุป
- `src/describe.js` ให้ AI อธิบายรูปและ PDF
- `src/ai.js` เรียก AI ตาม `AI_PROVIDER` (OpenAI หรือ Claude)
- `src/tasks.js` งาน การเตือน และสรุปเช้า
- `src/db.js` ฐานข้อมูล SQLite
- `src/export-parser.js` + `src/export-cli.js` อ่านไฟล์ export ของ WhatsApp แล้วสรุป
