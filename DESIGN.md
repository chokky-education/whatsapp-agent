# Warroom visual system

Approved production design (2026-11-18): **SOUVANNARATH ARCHITECT Digital CI v0.1** (`Concept A: Structure / Plan`) applied to the Horizon UI Bento structure in `warroom/public/index.html`, `warroom/public/style.css`, `warroom/public/app.js`, and `warroom/public/view-model.js` (and synced to `docs/prototypes/warroom-horizon.{html,css,js}`).

Operator dashboard for a Thai-speaking team. The interface prioritizes evidence, its age, and AI provider/model visibility. Product decisions live in `PRODUCT.md`, `docs/PLAN-warroom-status.md`, and `docs/superpowers/specs/2026-11-16-warroom-horizon-cozy-design.md`.

- **Brand assets & color tokens:** Official geometric 'S' SVG logo and lockup assets live in `warroom/public/assets/{symbol_dark,symbol_light,primary_logo_dark,primary_logo_light}.svg` and `warroom/public/favicon.svg` (never redrawn). Light mode uses Bone & Charcoal (`--bg: #F7F7F5`, `--surface: #FFFFFF`, `--surface-soft: #EFEEEA`, `--surface-tint: #E8E6E1`, `--text: #1F1F1F`, `--secondary: #595959`, `--border: #DAD9D4`, `--border-strong: #9B9B9B`, `--accent: #1F1F1F`, `--wood: #71716C`, `--ok: #2C6D50`, `--warning: #855C1C`, `--error: #AE3434`, `--focus: #2563A5`) and Dark mode uses Charcoal (`--bg: #161616`, `--surface: #202020`, `--surface-soft: #292929`, `--text: #F7F7F5`, `--secondary: #B9B9B5`, `--border: #383838`, `--border-strong: #717171`, `--accent: #F7F7F5`, `--ok: #91D5B3`, `--warning: #E3C38A`, `--error: #F0A0A0`, `--focus: #8DB7E8`) with `data-theme` toggle, `prefers-color-scheme: dark`, and `prefers-contrast: more` overrides. Architectural 1px neutral borders and 4–8px corner radii replace decorative gradients and capsule pills. Every color state carries a text label.
- **Typography & icons:** Self-hosted `WarroomThai` (`/fonts/thai-0.woff2`–`thai-8.woff2`, TrueType format with OFL license in `warroom/public/fonts/`) and self-hosted Flaticon Uicons (`/assets/flaticon-uicons.woff2` with `/assets/FLATICON-LICENSE.txt` and visible footer attribution). Zero third-party font or icon requests (external requests limited to Google Identity Services when signing in).
- **Layout & data honesty:** Desktop uses a 290px sidebar with a right-edge active indicator pill, floating top utility pill (live search, admin-only alerts shortcut, Light/Dark toggle, guidance dialog trigger, account badge), 5 KPI cards, 4 backend-real RBAC-aware charts (`#rhythm-card` stem+dot latency chart for `admin` `status.calls` with `#conn-strip` separated above and a 2-lane event timeline without ms for `team`; `#capsule-card` per-capability averages with explicit `0 ครั้ง / ยังไม่เรียก` for uncalled capabilities; `#traffic-card` 7-hour stacked event histogram from `/api/history`; `#pie-card` queue `waiting`/`running`/`oldestAt` ring and stats), plus the 5-capability table, capability detail card, recent events checklist, and team card. Mobile stacks navigation cleanly with zero horizontal overflow.
- **Evidence rules:** Clearly distinguish connection state, completed send, delivery acknowledgement, configured model, and response model. Missing evidence remains unknown (`ยังไม่ทราบ` / `ยังไม่เรียก`). Stale telemetry (`stale` or failed fetch) keeps an explicit banner and timestamps without showing a false healthy state. Reduced motion (`prefers-reduced-motion: reduce`) disables transitions and keyframe animations.
- **Security & CSP:** Served under `warroom/src/worker.js` strict `content-security-policy` (`style-src 'self'` without `'unsafe-inline'`, `script-src 'self' https://accounts.google.com/gsi/client`). Dynamic bar/ring styles are applied solely via CSS classes, SVG attributes, and DOM CSSOM properties (`.style.*`), never inline HTML `style="..."` attributes or inline scripts. Native forms/dialogs use `textContent` and `el()`/`svgEl()` DOM construction.
- **Development preview:** `#demo-banner` appears only in the localhost development server (`warroom/dev.mjs` at `http://127.0.0.1:4173`). Production deployment excludes dev/test scripts and all chat or credential files.
